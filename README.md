# San Diego Recommendations

San Diego has a lot to offer in terms of things to see, experience, and eat. I created this list to share with some friends who were planning a trip there.

We lived there for a total of 16yrs (the longest consecutive stretch being 11yrs). We've since moved away, but  still visit regularly to see family and friends.

This list started as a Google Doc I would share. I moved it here to make it easier to update myself, and with suggestions from others.

## Contributing

Recommendations live in the Markdown documents in `docs/` and the webpage is built with [Zensical](https://zensical.org).

If you have an update or a suggestion, create an issue.

If you feel comfortable editing the doc directly, you can create a pull request.

## Local preview

If you've cloned this repo and made edits, you can preview your changes with:

    uvx --with-requirements requirements.txt zensical serve

> **Note**: you need to have `uv` installed.

Then open http://localhost:8000. Edits to the markdown reload automatically.
